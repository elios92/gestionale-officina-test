# GDO Bike — preparazione GitHub Releases

Questo repository è **pubblico** ed è attualmente un punto di preparazione per le future **Release APK di GDO Bike**. Non è la copia completa e verificata del progetto Android e **non è ancora un canale di aggiornamento operativo**.

- Le Release ufficiali devono essere pubblicate solo dopo autorizzazione, compilazione, firma, test e verifica di compatibilità.
- Nessun APK di debug, backup, database, dato cliente, credenziale o chiave di firma va pubblicato.
- I sorgenti proprietari non devono essere caricati qui automaticamente: prima va decisa la strategia di visibilità e sincronizzazione.
- L'app potrà **rilevare e notificare** una nuova versione; l'installazione resterà una scelta dell'utente. Le librerie Gradle si aggiornano solo nell'ambiente di sviluppo.

**Procedura e requisiti di sicurezza:** [docs/RELEASES.md](docs/RELEASES.md).

Stato al 13 ottobre 2026: repository di preparazione; la pubblicazione di Release e il collegamento effettivo al client Android non sono stati ancora verificati o completati.
